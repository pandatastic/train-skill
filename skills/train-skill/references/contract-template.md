# Compact delivery contract

Use only fields that affect execution. One record, not a form per dispatch.

## Agreement

- Project/workspace, starting candidate and applicable instructions:
- Requested outcome and observable acceptance:
- Stage: QUESTION / PROPOSAL / MANIFEST / EXECUTE:
- Destination and permitted systems/actions:
- Explicit exclusions, approval conditions and recovery boundary:
- Overall effort/recovery boundary; existing user limits:
- Required checks and any known personal access/consent dependency:
- Verification profile and existing task/environment, when needed; required persona/browser/provider capability:

Execution includes necessary implementation, setup, integration, ordinary repairs and delivery tooling within this agreement. Routine delivery should be automated. Do not infer new authority or a later destination.

## Cars, only when needed

| Task ID / role | Exact model / effort | Environment / candidate | Owned work and required result |
|---|---|---|---|
| | | | |

Use [model routing](car-model-routing.md). Verify actual configurations when creating tasks; preserve active assignments. A manifest alone creates/starts nothing. Separate Builder and independent Closer; add a Promoter only for a concrete ownership need.

## Current checkpoint

- Approved requirements/source references and current candidate:
- Active assignments:
- Passed checks and evidence links:
- Reusable environment owner/identity and evidence cursor; persona lifetime through review, if applicable:
- Consolidated unresolved defects and actual blockers:
- Next action and responsible car:
- Relevant cumulative effort/failures and uncertain operation state:

Update at material changes; keep history separately. Detour decisions need at most a short explanation of necessity, authority and the smallest sufficient action. No routine extra approval gate or seal.

## Closure

- PASS / VETO / BLOCKED, with outcome and exact artifact:
- Decisive checks, actual mutations, limitations and cleanup:
- Any remaining user decision:
- Observed interventions, repeated checks, tooling effort and elapsed delivery time (when available):

Do not claim full acceptance from stage-specific evidence. Stop at the authorized outcome.
